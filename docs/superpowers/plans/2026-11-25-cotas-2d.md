# Medidas extras na planta 2D — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Botão "Mostrar medidas" ao lado de "Baixar PNG" que desenha na planta 2D as cotas do fundo, mesa, balcão, espaço livre até a fachada, porta até as paredes e móveis até a fachada.

**Architecture:** Função pura `planMeasurements(layout)` devolve as cotas em mm no sistema da planta (x para a direita, y para baixo, fachada em y = roomDepthMm); o `FloorPlan` ganha a prop `showMeasures` e desenha cada uma com o `Dimension` que já existe; o `App` guarda o liga/desliga em estado local.

**Tech Stack:** React 19, TS, SVG, vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-25-cotas-2d-design.md`

## Global Constraints

- Texto das cotas com `formatMeters` (ex.: `2,00`); tamanho de móvel como `2,00 × 0,80`.
- Item ausente (porta, mesa, balcão, cadeiras) não gera cota; distância < 50 mm não gera cota.
- Começa desligado; não é salvo; vale nas 4 abas; PNG/PDF saem como a tela.
- Rótulo do botão: `Mostrar medidas` / `Ocultar medidas` (`aria-pressed`).

## Review Focus

- Máquinas na lateral direita (`machineWall: "right"`): o fundo fica do lado direito da planta — teste em Task 1.
- Balcão encostado na fachada (distância 0): sem cota — teste em Task 1.
- Projeto sem porta e sem móveis: só as cotas do fundo e do espaço livre — teste em Task 1.
- Loja sem máquinas: sem quebrar (fundo só com a área técnica) — teste em Task 1.
- Botão some fora da aba 2D, como os de exportar — coberto pelo bloco existente em Task 2.

### Task 1: `planMeasurements`

**Files:** Create `app/src/viewer2d/measurements.ts`, `app/src/viewer2d/measurements.test.ts`.

**Interfaces — Produces:**
```ts
export interface PlanMeasure { id: MeasureId; x0: number; y0: number; x1: number; y1: number; text: string } // mm, horizontal (y0 = y1) ou vertical (x0 = x1)
export type MeasureId = "fundo-largura" | "fundo-comprimento" | "livre-fachada" | "porta-esquerda" | "porta-direita" | "mesa" | "balcao" | "balcao-fachada" | "cadeiras-fachada";
export function planMeasurements(layout: Layout): PlanMeasure[];
```
Regras (plano = coordenadas da planta): faixa do fundo = da parede das máquinas até a linha do drywall (`back`: y 0..drywall.y; `side` esquerda: x 0..drywall.y; `side` direita: x W−drywall.y..W); `fundo-largura` horizontal e `fundo-comprimento` vertical, 200 mm para dentro da faixa. `livre-fachada`: `back` vertical do drywall até a fachada a 250 mm da parede direita; `side` vertical do fim da fileira (maior `y + depthMm`) até a fachada, 250 mm salão adentro da linha do drywall. Porta: horizontais a 250 mm da fachada, de 0 até `fd.x` e de `fd.x + fd.width` até W. Mesa/balcão: cota no lado maior do retângulo, 150 mm para fora, texto `L × P` (maior × menor). `balcao-fachada` e `cadeiras-fachada` (cadeira de maior `y + height` em `furniture.poufs`): vertical da borda de baixo até a fachada, no centro x do item.
